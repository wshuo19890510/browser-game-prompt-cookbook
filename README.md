# Browser Game Prompt Cookbook

A reusable set of compact game briefs for prototyping small, playable browser games. Each row pairs a one-sentence prompt with a genre, core loop, and a playability check.

The examples are designed for generators that accept a short natural-language idea and offer common options such as genre, visual style, difficulty, power-ups, timers, and enemy count. They are prompts, not claims that a specific generated result was tested. The prompt field stays below 240 characters, matching the current WordstoGame input limit observed on its homepage.

## Files

- `prompts.csv` — 24 editable prompt briefs with objective, loop, and a concrete manual playability check.
- `README.md` — usage notes and scope.

## How to use

1. Pick a prompt and paste the sentence into a text-to-game generator.
2. Set the closest available genre, style, and difficulty controls.
3. Play for one full objective cycle. Record whether the objective, controls, and failure or success condition are clear.
4. Edit one mechanic at a time and compare the result.

A playability check is a human checklist, not a benchmark score. For repeatable comparisons, use the same generator, settings, device, and prompt version, and record the date and observed result yourself.

## Source and scope

The prompt length and available example controls are based on the public WordstoGame homepage: https://wordstogame.com/. The prompt ideas and manual checks in this repository are original examples; they are not user testing data, performance measurements, or endorsements.
